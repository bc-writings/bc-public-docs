Usages classiques :

$\intervalO{a, b}$
\quad
$\intervalOC[\big]{a, b}$

$\intervalCO{\dfrac{1}{2}, \dfrac{2}{3}}$
\quad
$\intervalC[\Big]{\dfrac{1}{2}, \dfrac{2}{3}}$
\quad
$\intervalO*{\dfrac{1}{2}, \dfrac{2}{3}}$

$\intervalOC{-\infty, b}$
\quad
$\intervalO{a, +\infty}$
\quad
$\intervalCO{a, \infty}$

$\intervalO{-\infty, \infty}$
\quad
$\intervalO{-\infty, +\infty}$

$\intervalO{1, 2} \cup \intervalCO{2, 3} = \intervalO{1, 3}$


\medskip


Avec un autre séparateur :

$\intervalC{a ; b}$
\quad
$\intervalOC{a .. b}$
\quad
$\intervalO{-\infty .. +\infty}$


\medskip


À la main :

$]1, 2[ \cup [2, 3[ = ]1, 3[$
